# SET-M33

## Overview

SET-M33 is an antimicrobial peptide that has been extensively studied in recent years. It is a cationic non-natural peptide built in a branched form that makes it more resistant to degradation in biological ﬂuids. SET-M33 has shown efﬁcacy against a number of Gram-negative multi-drug and extensively drug-resistant clinical isolates.
