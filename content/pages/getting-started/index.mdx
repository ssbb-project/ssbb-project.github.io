## 🔬 Data Collection Workflow

The library aggregates data across multiple stages:

### 1. **Compound Identification**
- NDO structures collected from partner research groups  
- AMP sequences sourced from consortium laboratories  
- Standardized format using SMILES, InChi, and FASTA (for peptides)

### 2. **Structural Characterization**
- NMR, MS, and chromatographic profiling  
- 3D structural modeling performed using consortium computational tools  
- Quality checks performed before data integration

### 3. **Experimental Data Acquisition**
- Antimicrobial assays  
- Prebiotic activity screening  
- Microbial interaction experiments

### 4. **Validation & Curation**
- All data reviewed by consortium chemists, microbiologists, and bioinformaticians  
- Cross-checking with external databases when available
